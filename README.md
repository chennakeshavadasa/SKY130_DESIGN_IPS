# SKY130_DESIGN_IPS

This repository contains a collection of reusable analog and mixed-signal IP blocks designed using the SKY130 PDK. The goal of this project is to provide modular, well-organized design blocks that can be integrated into future ASIC and custom IC designs, reducing redesign effort and improving development efficiency.

## Goals

- Build a growing library of reusable SKY130-based IP blocks
- Encourage modular and scalable analog/mixed-signal design practices
- Enable easier integration of verified circuit blocks into future projects
- Provide open access to reference implementations, schematics, layouts, and simulation setups
- Encourage community contributions and collaborative development

## Contributions

Users are welcome to contribute additional IPs, improvements, simulation testbenches, documentation, or layout implementations to expand the repository and improve its usefulness for the open-source silicon community.

I will also continue adding more IP blocks and designs whenever time permits and based on availability. The aim is to gradually build a useful collection of reusable SKY130 design components for future projects and for the broader open-source hardware community.

All designs are intended to be reusable and easily portable within SKY130-based projects.
